# 角色资产提示词模板（给 Codex / Grok 生成像素角色用）

这份是给**人**看的：Claude 写提示词，你贴给生图工具（Codex、Grok 等），图存进约定的文件夹，说一声"好了"，Claude 去读图、切图。
分工和原理见 [`image-assets.md`](image-assets.md)。

这套流程在《演》里跑通了。核心只有一条：**先定一张"标准像"，以后每张图都附上它**。生成器不记得上一张画了什么，
只认你这次附上的图。

## 一、四步流程

| 步 | 出什么 | 附什么参考图 | 为什么 |
|---|---|---|---|
| 1 | 单人标准像（1:1，一个人，正面站立） | 角色原设定图 | 定下画风、头身比、配色。这张不满意就一直重出，后面全靠它 |
| 2 | 合照（所有角色并排，同一条地平线） | 每个角色的标准像 | 定下角色之间的相对高矮和线条粗细。**多角色的片子必须做这一步** |
| 3 | 表情表（3×2，同一站姿只换脸） | 该角色的标准像 | 一张图里出的六格最一致，可以做口型和眨眼 |
| 4 | 动作表（3×2，六个动作） | 该角色的标准像 | 同上 |

背景单独出，不附角色图。

## 二、开场规则（每个新对话第一条）

```text
接下来我给你几段图片描述。规则：
1. 每段直接调用图像生成工具生成一张图，不要改写或扩写我的描述，不要委托别的步骤。
2. 风格是高清像素画（pixel art）：硬边、无抗锯齿、无渐变、无模糊，色块平涂，深色单线描边，像素颗粒清晰可数。
3. 角色图的背景必须是纯色 #FF00FF（洋红）。整张图没有文字、字母、数字、水印、边框、阴影、地面、特效符号。
4. 分辨率尽量高。保存到【文件夹路径】，文件名用方括号里的名字，完成后只回复路径。
```

## 三、各步模板（【】里换成你的内容）

**1. 标准像**

```text
[【角色名】_ref.png]
画面比例 1:1。一个角色，正面全身站立，居中，占画面高度约 85%，脚底在画面下方约 5% 处，身体轮廓不被画面边缘裁掉。
角色：以我附上的设定图为准。【三到五个必须保留的特征：体型、主色、标志物】。【要去掉或简化的东西】。
姿势：双脚并拢站直，【手的位置】。表情：【一种】。
```

**1b. 让新角色和已有角色同一画风**（附两张：A = 画风样板，B = 新角色的原设定）

```text
[【角色名】_ref.png]
画面比例 1:1。我附了两张参考图。
参考图 A 只用来决定画法：描边粗细、像素颗粒大小、身体比例、四肢的画法、眼睛和嘴的画法，全部照 A。
参考图 B 只用来决定这个角色是谁：【颜色、标志物、嘴型等特征】。不要照搬 B 的身材比例和画法。
画一个角色，正面全身站立，居中，占画面高度约 85%。它和参考图 A 里的角色【一样高 / 高半个头】，【腿和脚的画法与 A 相同】。
```

**2. 合照**（附上每个角色的标准像）

```text
[lineup.png]
画面比例 16:9。把我附上的【N】个角色画在同一张图里，从左到右是【名字顺序】，正面站立，互不接触，间隔均匀。
所有角色的脚底在同一条水平线上。相对高度：【谁和谁一样高，谁高多少】。每个角色的描边粗细、像素颗粒大小完全相同。
每个角色的样子和各自的参考图保持一致，不要互相混合特征。
```

**3. 表情表**（附上标准像）

```text
[【角色名】_faces.png]
画面比例 3:2。3 列 × 2 行共六格，格子大小相同、排列整齐，角色之间留出明显空隙、互不接触，不画格子线。
同一个角色，以我附上的标准像为准。六格的身体姿势和大小完全相同，脚底在同一水平线上，只有脸不同。
第一行：1.【表情】 2.【表情】 3.【表情】
第二行：4.【表情】 5.【表情】 6.【表情】
```

要口型就写："第 2 格和第 1 格完全相同，只是嘴张开"。要眨眼就写："只是眼睛闭上"。

**4. 动作表**（附上标准像）

```text
[【角色名】_poses.png]
画面比例 3:2。3 列 × 2 行共六格，格子大小相同、排列整齐，角色之间留出明显空隙、互不接触，不画格子线。
同一个角色，以我附上的标准像为准，每格里角色的大小一致，脚底在同一水平线上。六格是六个不同的动作：
第一行：1.【动作 + 表情 + 手里的东西】 2.… 3.…
第二行：4.… 5.… 6.…
```

**5. 背景**（不附角色图）

```text
[bg_【场景名】.png]
画面比例 16:9。【场景】，正面平视，没有任何人物和角色。
【从左到右、从远到近描述有什么】。光：【光从哪来、什么颜色】。配色：【三四种主色】。
画面【哪一块】保持空旷干净，不要放道具，那里要站人 / 叠加界面。
```

## 四、出了问题怎么说（直接回给 Codex）

| 现象 | 回一句 |
|---|---|
| 背景不是纯洋红，有渐变或杂色 | 背景必须是完全均匀的纯色 #FF00FF，重新生成这一张，其他不变 |
| 格子里的人大小不一 | 六格里角色必须一样大，脚底在同一条水平线上，重新生成 |
| 角色互相挨着或被裁掉 | 每格之间留更宽的空隙，角色完整不被裁切，重新生成 |
| 画成了柔和的插画，不是像素画 | 要硬边像素画：无抗锯齿、无渐变、无模糊，重新生成 |
| 加了字、对话气泡、速度线、星星 | 去掉所有文字和特效符号，只留角色本身，重新生成 |
| 衣服或颜色和标准像不一样 | 服装和配色必须和我附的参考图完全一致，只改【表情 / 动作】，重新生成 |
| 只有一格不好 | 第【N】格【哪里不对】，其余五格保持不变，重新生成整张 |
| 两个角色画风不一致 | 用模板 1b 重出其中一个的标准像，再做合照 |

## 五、验收清单（发给 Claude 之前自己看一眼）

- 背景是不是一整片洋红
- 每格的人是不是一样大、站在一条线上、互不接触
- 有没有多出来的字或符号
- 脸、衣服、颜色和标准像对不对
- 多角色：合照里的高矮是不是你要的

发来之后 Claude 用 `scripts/pixelize.mjs` 切图：抠掉洋红、按网格切开、降成几档分辨率。
