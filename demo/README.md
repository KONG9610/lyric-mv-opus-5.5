## How it was made · 制作过程

One conversation, start to finish: questions first, a storyboard, model sheets for the two band characters drawn from
the band's reference sheets, a first minute, then the whole song, then four rounds of revisions (a rocket instead of a
shadow, a ticket swallowed instead of a stamp on the forehead, a hand-lettered title, heavier and then lighter type).
The pitfalls list in the skill is what that conversation learned.
